# Caravan Full Script - No Directions podcast package

Local podcast-feed package generated from the existing page-by-page `Full Script - No Directions` MP3s.

- `feed.xml` is built with the configured future base URL.
- `audio/` contains 85 MP3 enclosure files, one per script page, pages 04-88.
- Stage directions/director lines are omitted by the source manifest.
- This package is not published. A public feed URL needs explicit approval first.
